# 08: 多单元合同审批与签署

Status: open
Label: ready-for-agent
Type: task
Blocked by: 04, 07
Spec: [平台Spec](../spec.md)
User stories: 22, 46, 48, 49, 50, 51, 52, 53, 54, 56, 57, 58

## What to build

合同专员为同一承租企业、同一园区的多个完整出租单元创建共同租期草稿，逐单元保存面积、价格与费用条款快照，后续房源价格调整不改变已保存快照。审批链为财务复核费用、园区负责人终审，提交人不得审核自己的单据；驳回后修改原草稿并保留历轮审批，不生成重复合同。签署登记真实签署日期与扫描件版本，不称电子签章。

合同日期包含首尾，同日交叠冲突、次日相邻允许；多单元按排序加锁，任一单元冲突整体回滚；审批通过原子接管对应意向暂占，旧到期任务不得误释放；免租期间仍保留占用。未签合同可取消并释放预订，已有资金事项继续保留跟踪入口，不删除历史；实际收款后的取消与退款分支在 11 及 14/16 接入。

- 草稿记录企业、园区、共同租期与各单元；单元只能是完整出租单元，跨园区或增租另签。
- 审批轮次记录提交人、复核人、终审人、时间与意见，驳回原轮次保留。
- 签署记录真实签署日期、扫描件版本与经办人，扫描件按私有文件契约保存。
- 合同占用以单元区间记录，与意向暂占、实际占用分别表达。
- 多单元写入按单元排序加锁，冲突时整体回滚并返回可定位的冲突单元。
- 取消未签合同保留原记录与资金跟踪入口，不物理删除。
- 合同与附件读取按企业归属与园区范围鉴权。

## Acceptance criteria

- [ ] Migration 建立合同、审批轮次、单元快照与签署附件表，空库迁移后可启动并使用真实 MySQL 验证。
- [ ] 同企业同园区多完整单元共同租期草稿可创建，逐单元面积与价格快照持久化；之后修改单元价格不改变快照。
- [ ] 审批按财务复核、负责人终审顺序执行，提交人自审被拒绝；驳回后同一草稿进入新轮次并保留历轮记录。
- [ ] 含首尾日期的区间交叠被拒绝，次日衔接被允许，边界用例通过真实 MySQL 验证。
- [ ] 多单元中任一单元区间冲突导致整体回滚，不留下部分单元或半张合同记录。
- [ ] 审批通过原子接管意向暂占；接管后旧到期扫描不释放该单元，误释放回归通过。
- [ ] 含免租期的合同在免租期间仍保留占用，不被判断为空房。
- [ ] 签署登记真实日期与扫描件版本，签署与审批分别记录；未签取消释放预订并保留既有资金跟踪入口与历史记录。
- [ ] 企业 A 的账号不能读取企业 B 的合同与附件，越权请求被拒绝且不泄露对象是否存在。
- [ ] UI 可完成草稿编辑、审批操作与签署登记，结果持久化到 MySQL；HTTP/API 测试输出作为证据保留，未执行的验证不写为通过。

# 18: 续租押金转结

Status: open
Label: ready-for-agent
Type: task
Blocked by: 12, 17
Spec: [平台Spec](../spec.md)
User stories: 83

## What to build

续租合同可经批准将原合同押金转入新合同，成对记录双边流水，不产生新的现金到账。

- 续租合同可指定原合同押金来源与金额发起转结申请；申请冻结来源押金额度，冻结额度不可重复使用。
- 经批准后执行：原合同押金出账、新合同押金入账，成对写入押金流水并在同一事务完成，双边记录互相关联且来源可查。
- 转结金额不超过来源押金可用余额；不产生现金收款、到账记录或租金收入。
- 驳回或撤销释放冻结额度，原合同余额不变且不产生流水。
- 执行幂等：重复或并发执行不重复转结，不超余额。
- 不同企业或非关联合同的转结被拒绝；转结后的来源流水标记为已被关联使用，供票据 19 校验依赖。

## Acceptance criteria

- [ ] 从原合同押金来源发起转结申请后冻结额度，可用额度减少。
- [ ] 批准执行后同一事务产生旧合同出、新合同入两条互相关联的流水，双边来源可查。
- [ ] 转结不新增收款、现金到账或租金收入记录。
- [ ] 转结金额超过来源可用余额被拒绝；重复或并发执行只转结一次。
- [ ] 驳回或撤销释放冻结额度且不产生流水。
- [ ] 不同企业或非关联合同的转结被拒绝。
- [ ] 转结事务失败时，冻结额度、双边流水与余额均不发生部分变更。
- [ ] 转结后来源流水标记被关联使用，19 可校验依赖。
- [ ] 非财务或无权限账号批准转结被拒绝；他企业转结不可见。
- [ ] UI 可申请、批准并查看双边明细，Flyway migration 可在空库升级，真实验证证据保存。

## Context

本票对应 [平台Spec](../spec.md) Implementation Decisions 第 31 条与 User Stories 83。押金转结是内部资金转移，不产生现金与租金收入，术语见 [GLOSSARY](../../../GLOSSARY.md)。

来源与可用额度来自票据 12 的押金台账，续租关联合同来自票据 17；成对流水须在同一事务完成并标记被关联使用，供 19 拒绝孤立红冲。合同边界见 [ADR 0002](../../../docs/adr/0002-whole-unit-contract-boundary.md)，事务一致性见 [ADR 0001](../../../docs/adr/0001-modular-monolith.md)。

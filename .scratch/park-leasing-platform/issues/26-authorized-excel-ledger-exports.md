# 26: 授权台账Excel导出

Status: open
Label: ready-for-agent
Type: task
Blocked by: 25
Spec: [平台Spec](../spec.md)
User stories: 103, 106

## What to build

运营人员以与页面相同的筛选条件同步导出授权台账或统计为有效 Excel，文件列与页面明细一致、可复核；单次最多 10000 行，超限提示缩小范围。导出前强制执行园区、企业、成员数据权限。实现不得全量 list 后在内存中伪装流式或静默截断，查询本身受上限约束。

导出是对页面可见数据的同口径快照，不改变业务状态，也不额外放宽可见列；导出记录与页面对账以同一筛选条件为基准。

## Acceptance criteria

- [ ] 授权用户按页面筛选导出授权台账或统计 Excel，列、金额与日期格式有效，抽样与页面明细一致可复核。
- [ ] 单次导出上限 10000 行：9999 与 10000 行成功，10001 行返回“缩小范围”业务提示且不生成不完整文件。
- [ ] 导出前执行园区、企业、成员数据权限，结果等同页面可见范围；越权筛选不返回未授权数据。
- [ ] 实现不以全量 list 后在内存伪装流式或静默截断规避上限，查询在真实 MySQL 上受上限约束。
- [ ] 权限边界：无导出权限或超出园区范围的请求被拒绝（403/404），包括直接构造筛选参数。
- [ ] 导出文件可由标准工具打开并通过格式检查（表头、列数、数值列类型）。
- [ ] UI 触发导出的入口与页面筛选联动，导出期间有明确状态反馈。
- [ ] 证据：真实请求/响应与导出文件样例，含临界值与越权用例；未执行项如实标注。

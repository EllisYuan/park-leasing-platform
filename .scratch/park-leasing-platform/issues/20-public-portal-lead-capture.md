# 20: 招商门户与匿名留资回访

Status: open
Label: ready-for-agent
Type: task
Blocked by: 06
Spec: [平台Spec](../spec.md)
User stories: 23, 24, 25, 26, 27, 39, 107

## What to build

访客可用的公开招商门户，以及匿名留资进入招商回访的最小闭环。门户展示园区介绍、房源列表与详情，支持按厂房条件筛选；只展示公开且启用的房源，指导价可公开而底价保持私有。访客无需注册、短信或验证码即可提交联系资料与需求，提交持久化到数据库并出现在招商回访工作台；工作人员回访后更新内部处理状态，该进度不向访客暴露。留资有频率与去重限制。运营人员可维护房源的公开展示状态。房源图片按既有文件契约的公开/私有边界提供，本票不新建公开存储体系。门户在手机宽度可用。

留资只形成回访对象，不产生租赁占用，也不自动建档为已核验企业；招商侧按 06 的线索与回访能力承接，不另建客户主数据。门户只读公开数据，任何后台操作不通过门户接口暴露。

## Acceptance criteria

- [ ] 访客在门户浏览园区、房源列表，按厂房条件筛选并查看详情；数据来自 MySQL 中“公开且启用”的房源，停用或未公开房源不出现在列表、详情与筛选结果（HTTP 空结果或 404）。
- [ ] 门户页面与接口响应中不出现底价、合同联系人、企业身份与内部跟进记录；指导价按维护值展示。
- [ ] 匿名留资无需账号与短信，提交联系人、企业名称和需求后写入 MySQL 并进入招商回访队列；同一联系方式的重复提交按窗口去重或合并，超过频率限制被拒绝。
- [ ] 招商人员可查看留资、记录回访结果并推进内部状态；内部进度仅后台可见，门户不提供查询接口。
- [ ] 权限边界：未登录访客只能访问公开接口；后台留资列表与操作需招商权限并受园区数据范围约束，越权请求返回 403/404。
- [ ] 房源图片经既有文件契约的公开/私有边界访问，私有附件不因门户而可匿名下载。
- [ ] 必要 migration（房源公开状态、留资与去重约束）可在空库执行并保留既有数据。
- [ ] UI（门户列表/详情/留资表单、后台展示状态与回访列表）可操作且数据落库；手机宽度关键页面可用。
- [ ] 证据：保留覆盖上述行为的真实 HTTP 响应与 MySQL 查询输出，截图注明来源；未执行项如实标注。

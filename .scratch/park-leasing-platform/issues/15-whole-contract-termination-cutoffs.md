# 15: 整合同提前终止与费用截断

Status: open
Label: ready-for-agent
Type: task
Blocked by: 09, 13
Spec: [平台Spec](../spec.md)
User stories: 84, 85, 86, 88, 92

## What to build

合同专员可发起整份租赁合同的提前终止，经园区负责人批准后按批准截止日重算费用、释放合同预订，实际交还单独登记。

- 提前终止申请由园区负责人批准，批准记录终止日期与依据；原合同租期保持不变，不删除历史。
- 费用截止日默认等于批准终止日；协议例外由负责人另行明确批准费用截止日与合同预订截止依据，两项事实可使用不同日期，财务不得直接改原日期。
- 财务按批准费用截止日重算该合同费用，差额通过票据 13 的账单调整生成，不覆盖历史账单金额。
- 合同预订区间按批准截止释放；实际占用解除以实际 OUT 单独登记，未登记 OUT 的单元仍不能交付下一家企业。
- 终止后欠费继续可查询并继续登记收款，终止不自动免债。
- 损坏赔偿与逾期占用费只能由人工依据提交并经审批入账，系统不自动认定或计算。
- 不支持部分退租；对已终止合同重复发起终止被拒绝。

## Acceptance criteria

- [ ] 负责人批准提前终止后，原租期保持不变，终止记录、批准日期与依据持久化。
- [ ] 费用截止日默认等于终止日；负责人分别批准例外费用截止与预订截止后两日期可不同并各自可查。
- [ ] 按批准费用截止重算产生关联调整（经 13），历史账单金额不被覆盖。
- [ ] 合同预订按批准截止释放；实际 OUT 未登记时该单元仍不可交付下一户。
- [ ] 终止后欠费仍可查询并可继续登记收款。
- [ ] 损坏赔偿或逾期占用费未经人工审批不入账。
- [ ] 费用截止、合同预订截止与实际 OUT 在 UI 与查询中分别展示，不合并为单一日期。
- [ ] 终止批准事务失败时，原合同、账单与预订状态保持不变。
- [ ] 非负责人批准或重复终止被拒绝；部分退租请求被拒绝。
- [ ] UI 可完成申请、批准与事实查看，Flyway migration 可在空库升级，真实验证证据保存。

## Context

本票对应 [平台Spec](../spec.md) Implementation Decisions 第 22—23 条与 User Stories 84—86、88、92。提前终止保留原租期，费用截止、合同预订截止与实际 OUT 是不同事实；术语见 [GLOSSARY](../../../GLOSSARY.md)。

费用重算差额通过票据 13 的关联调整落地；合同状态与签署事实由票据 09 提供。整合同边界（不做部分退租）见 [ADR 0002](../../../docs/adr/0002-whole-unit-contract-boundary.md)，单库事务见 [ADR 0001](../../../docs/adr/0001-modular-monolith.md)。

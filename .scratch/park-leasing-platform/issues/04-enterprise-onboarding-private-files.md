# 04: 企业核验开户与私有资料

Status: open
Label: ready-for-agent
Type: task
Blocked by: 02
Spec: [平台Spec](../spec.md)
User stories: 10, 11, 12, 17, 104, 105

## What to build

运营人员核验企业资料与联系人后建立企业档案，并创建归属该企业的企业管理员账号；一个企业账号只归属一家企业。营业执照等图片与 PDF 以私有文件方式上传并绑定业务归属，下载经鉴权，不能通过可猜测或公开路径访问；默认单文件 20MB、内容类型白名单；未绑定临时文件按生命周期清理。

文件能力在本票内封装为可复用的私有文件服务，供后续合同附件、跟进附件与其他业务复用，但不建立公开存储。企业 A 与企业 B 的资料互相不可越权访问；执照上传不自动授予历史合同访问权。企业成员管理与企业内权限扩展在 23 接入，本票只交付企业管理员。

- 企业档案包含核验过的名称、联系人与联系授权依据；企业管理员账号由运营创建并绑定该企业。
- 账户与企业为多对一：同一企业可有多个账号，同一账号只能归属一家企业。
- 私有文件上传先写临时状态，绑定业务归属后才进入可下载状态，未绑定文件按生命周期清理。
- 下载以业务归属鉴权，可猜测路径、目录遍历与公开静态映射都不作为访问方式。
- 文件大小与内容类型在服务端校验，前端提示不作为唯一限制。
- 数据库元数据与存储文件的一致性在失败与清理路径上都有明确处理。
- 企业管理员登录后只能看到本企业资料与文件。

## Acceptance criteria

- [ ] Migration 建立企业、联系人、企业账号归属与文件元数据表，空库迁移后可启动并使用真实 MySQL 验证。
- [ ] 运营人员核验后创建企业与联系人关系，并创建企业管理员账号；该账号登录后的身份归属该企业。
- [ ] 同一企业账号尝试绑定第二家企业被拒绝，不产生双归属记录。
- [ ] 授权上传营业执照成功后文件私有存储，直接以猜测的公开地址访问返回拒绝，不产生公开可读链接。
- [ ] 文件下载要求认证与归属授权；企业 A 的账号不能下载企业 B 的文件，拒绝响应不泄露文件是否存在。
- [ ] 超过 20MB 的文件被拒绝，非图片/PDF 白名单类型被拒绝，返回可据此修正的提示。
- [ ] 未绑定的临时上传文件按生命周期清理，被授权绑定后的文件可下载；数据库元数据与实际存储状态一致。
- [ ] 企业 A 上传执照后仍不能读取企业 B 的历史合同，执照上传不推断历史合同归属。
- [ ] UI 可完成企业开户、执照上传与下载，操作结果持久化到 MySQL；越权账号看不到他人资料入口。
- [ ] 使用真实 MySQL 与真实认证上下文执行 HTTP/API 测试并保留原始输出，未执行的验证不写为通过。

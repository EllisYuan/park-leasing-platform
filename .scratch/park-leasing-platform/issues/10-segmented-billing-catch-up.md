# 10: 自然月分段账单与补漏

Status: open
Label: ready-for-agent
Type: task
Blocked by: 08
Spec: [平台Spec](../spec.md)
User stories: 63, 64, 65, 66, 67, 68, 69, 70, 71

## What to build

财务在租赁合同审批并签署后，即可为该合同生成按自然月分段的一次性预收应收账单，无需等待企业完成 IN 或登记实际占用。

- 租金与物业费均按元/平方米/月计价，计费面积取合同逐单元快照；租金与物业费分类成账，多单元明细逐条保留。
- 支持 1/3/6/12 个月付款周期，以合同开始月份月初为自然月锚点，首尾账期裁剪到真实合同日期，按自然月日历天数折算，大小月与闰年不近似处理。
- 期初连续免租期只减免租金，物业费照常计收；免租期仍属于占用区间。
- 计租日周年按合同约定复利递增单价，无递增条款不递增；跨周年的账期使用对应单价。
- 每条明细保留面积、单价、起止日期、自然月天数、周年次数与可复算算式；中间计算保留足够精度，分段明细四舍五入至分后汇总。
- 账单出单日与付款到期日分别约定并持久化，二者不互相推导。
- 定时出账与人工补跑调用同一出账服务；以合同与账期的唯一业务键防重，支持停机后按账期补漏；单合同失败留下可追查记录，不阻断其他合同。
- 运营后台可查看账单与逐单元算式明细，金额、期间与日期可直接复核。
- 押金分类账单不在本票生成，由票据 12 接入；收款不在本票，由票据 11 承接。

## Acceptance criteria

- [ ] 对已审批签署合同通过 HTTP 接口触发出账，生成租金与物业费分类账单；MySQL 中逐单元明细包含面积、单价、起止日期、天数、周年次数与算式。
- [ ] 首尾非整月按自然月日历天数折算，覆盖大小月与闰年样本，与独立人工基准一致。
- [ ] 期初免租仅减免租金，同账期物业费全额计收；计租日周年后的单价按约定复利递增。
- [ ] 出单日与付款到期日分别保存，UI 账单详情可展示并可复算每条明细结果。
- [ ] 同一合同同一账期重复出账（人工与定时各执行一次）不新增账单，业务键唯一。
- [ ] 模拟停机跨多个账期后补跑，缺失账单全部补齐且已出账不重复。
- [ ] 单合同计费失败被记录并可追查，其他合同照常出账。
- [ ] 未审批或未签署合同触发出账被拒绝并返回业务错误。
- [ ] Flyway migration 可在空库升级，并以真实 MySQL 集成验证保存请求、响应与查询输出证据。
- [ ] 验证证据保存真实输入输出，不预填通过结论。

## Context

本票是父 spec 计费主链的第一段，覆盖 [平台Spec](../spec.md) Implementation Decisions 第 24—26 条、Testing Decisions 的计费与出账覆盖项，以及 User Stories 63—71。术语以 [GLOSSARY](../../../GLOSSARY.md) 为准：应收账单、计租日、免租期均在本票生效，期初免租不免物业费。

出账与收款分离：本票止于生成应收账单，收款见票据 11；押金分类账单由票据 12 接入。自然月分段与业务键防重依赖单库事务与唯一约束，架构背景见 [ADR 0001](../../../docs/adr/0001-modular-monolith.md)；合同多单元快照边界见 [ADR 0002](../../../docs/adr/0002-whole-unit-contract-boundary.md)。具体技术版本尚未冻结，实施时以最小集成验证结果为准。

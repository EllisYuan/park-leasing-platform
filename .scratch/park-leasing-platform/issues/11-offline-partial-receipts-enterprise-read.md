# 11: 线下部分收款与企业查询

Status: open
Label: ready-for-agent
Type: task
Blocked by: 10
Spec: [平台Spec](../spec.md)
User stories: 16, 72, 73, 74

## What to build

财务可对一张应收账单登记多笔线下收款，企业账号可在企业中心跨园区查询本企业被授权合同的账单与收款明细。

- 每笔收款归属一张应收账单，实际到账日期、系统录入时间、收款方式、凭证与经办人分别保存，并使用独立业务号。
- 一张账单可多次部分收款，每笔金额为正且不得超过账单未收余额；并发登记不能造成累计超收。
- 同一业务号重复提交只记一笔收款。
- 部分付款后账单仍显示逾期事实与剩余未收金额，逾期不因部分付款消失。
- 企业账号查询范围由服务端从身份与企业归属解析，不信任前端提交的企业或资源 ID；跨园区查询仅限本企业被授权合同。
- 收款凭证等私有附件按业务归属鉴权下载，未授权请求被拒绝。
- 未签合同取消时，已登记收款保留并可见待处理状态，不在本票退款；实际退款由票据 16 接入。
- 本票只记录经核实的线下资金事实，不接支付渠道或银行对账。

## Acceptance criteria

- [ ] 对账单连续登记两笔部分收款，账单剩余金额正确递减；DB 保存各笔到账日、录入时间、方式、凭证、经办人与业务号。
- [ ] 金额为零、负数或超过剩余余额的请求被拒绝并返回业务错误。
- [ ] 同一业务号重复提交只产生一笔收款记录。
- [ ] 两笔并发收款在 MySQL 事务约束下不产生累计超收。
- [ ] 部分付款后账单仍标记逾期并展示剩余金额。
- [ ] 企业账号通过 HTTP 查询本企业跨园区授权合同的账单与收款明细；篡改企业 ID 访问他企业数据被拒绝。
- [ ] 私有收款凭证仅能通过业务归属鉴权下载，无权限请求被拒绝。
- [ ] 无财务权限的运营账号调用收款录入被拒绝。
- [ ] 未签合同取消后已收款项保留可查并显示待处理，本票不产生退款记录。
- [ ] UI 可完成收款录入与账单查询，Flyway migration 可在空库升级，真实验证保存请求、响应与查询输出。

## Context

本票对应 [平台Spec](../spec.md) Implementation Decisions 第 27 条、第 21 条（未签取消保留资金）与 Testing Decisions 的收款更正覆盖项，User Stories 16、72—74。术语见 [GLOSSARY](../../../GLOSSARY.md)：收款、应收账单；实际退款不在本票发生。

企业查询的身份与会话边界沿用 [ADR 0003](../../../docs/adr/0003-browser-session-authentication.md)，数据范围由服务端从身份与资源关系解析；资金并发一致性依赖单库事务，见 [ADR 0001](../../../docs/adr/0001-modular-monolith.md)。本票只记录线下资金事实，退款链路在 16。

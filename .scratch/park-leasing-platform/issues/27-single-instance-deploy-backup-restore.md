# 27: 单实例部署与备份恢复

Status: open
Label: ready-for-agent

Blocked by: 04
Spec: [平台Spec](../spec.md)
User stories: 108, 109

## What to build

本地启动与单实例部署说明和配置：后端 jar 与 MySQL 本地运行，Nginx 同源提供 SPA 与 API，Compose 可选。实际环境锁定版本并记录。未配置 HTTPS 时不冒充已启用；重启后重新登录。验证数据库与私有附件备份恢复到独立目标并核对，不覆盖原库与原附件。本票可先执行、不等财务模块；28 在最终 tip 重跑完整数据恢复。

备份恢复同时覆盖数据库与私有附件两类资产，缺一不视为完整；恢复后的环境独立运行，验证不向原环境保护写回。

## Acceptance criteria

- [ ] 按部署文档从干净环境启动后端 jar、MySQL 与 Nginx 同源 SPA/API，登录、分页与基本业务可用；Compose 为可选补充。
- [ ] 实际运行环境版本（Java、Maven、Node、MySQL、关键依赖）被记录，未验证的组合不声称支持；精确版本以本次验证结果为准。
- [ ] 重启应用后已有会话失效、需重新登录，符合既定会话方案；未配置 HTTPS 时明确标注 Secure Cookie 未启用。
- [ ] MySQL 备份恢复到独立验证目标，核对表、关联与既有业务数据；私有附件备份恢复后可按业务归属下载，未授权仍被拒绝。
- [ ] 恢复目标与原库、原附件存储隔离；原库数据不被覆盖或修改，验证后原环境仍可运行。
- [ ] 验证覆盖已有真实种子数据（含企业、合同、账单、附件）；财务相关部分未完成不阻塞本票，由 28 在最终集成版本重跑。
- [ ] 部署文档含操作步骤、配置说明与已知缺口（HTTPS、会话存储等），不写“已通过”或未执行的结论。
- [ ] 证据：真实命令的输入输出与恢复前后查询结果；未执行项如实标注。

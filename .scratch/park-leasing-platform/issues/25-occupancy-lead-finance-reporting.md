# 25: 经营、招商与资金统计

Status: open
Label: ready-for-agent
Type: task
Blocked by: 19
Spec: [平台Spec](../spec.md)
User stories: 100, 101, 102

## What to build

基于真实源数据的只读统计 UI 与 API。实际占用率按“实际占用计租面积 / 纳入出租范围面积”计算：维修中单元保留在分母，正式停用移出分母，未来预订单独展示。招商统计按同批线索与截至日的真实事件计算：阶段跳过不制造虚假漏斗，到期不抹除历史签约。资金统计区分账期应收核销、现金实际到账日与押金；押金不是租金收入，抵扣与转结不是现金，纯红冲不是退款；收退款为线下凭证记录。汇总可由明细复算，零分母给出明确结果，不写入未经测量的性能数字。

统计口径以既有业务表为准，不从人工算例或预置数值反推；页面与 API 使用同一口径，展示必要的计算说明但不复制完整业务明细。

## Acceptance criteria

- [ ] 实际占用率按实际占用计租面积除以纳入出租范围面积计算；维修中单元在分母、正式停用移出，口径在页面标注，未来预订分开展示。
- [ ] 招商统计基于同批线索与截至日真实事件：跳阶段不补造带看或转化，到期不抹除历史签约；以构造的跳阶段数据验证数字与明细一致。
- [ ] 资金统计区分账期应收核销、现金实际到账日与押金；押金不计入租金收入；抵扣与转结不计现金；纯红冲不视为退款。
- [ ] 汇总与明细可复算：抽样汇总值等于对应明细之和；零分母或无数据时显示明确说明，不报错也不伪造数字。
- [ ] 统计只读，不写业务表，不维护第二套业务事实（如引入缓存须可随时从源数据复算一致）。
- [ ] 权限边界：统计 UI 与 API 执行与其他入口相同的数据权限，仅返回授权园区范围，越权查询被拒绝。
- [ ] 园区、招商、资金三类统计 UI 可操作，手机基本可访问，数据来自真实 MySQL。
- [ ] 不写入未经测量的性能或可用性数字；证据保留真实查询输出与人工复算对照，未执行项如实标注。

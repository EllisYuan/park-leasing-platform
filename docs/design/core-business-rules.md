# 核心业务规则

状态：Q12—Q27 对应的业务与工程决定均已由用户逐轮确认；Q26—Q27 后的原回复为“全部确认”。本文为设计决定，没有代码或运行证据。总体范围见 [设计基线](platform-baseline.md)。

## Q12 登录与会话

第一方浏览器应用采用 Spring Security + 服务器 Session + HttpOnly Cookie。开发通过 Vite 代理访问后端，部署通过 Nginx 提供同源页面与 API；修改数据的请求启用 CSRF 防护，HTTPS 使用 Secure Cookie。

闲置30分钟后重新登录，不做长期免登录；允许多设备。退出销毁当前会话；账号停用、密码或授权改变后撤销相关会话或重新校验。第一版单实例且会话不持久化，后端重启重新登录。该确认取代旧规划未确认的 JWT 建议。具体 Spring Security/Boot 版本和配置仍待集成验证。

## Q13 企业开户

访客无需登录可留资和申请看房，招商人员跟进。运营核验企业资料及联系人授权后建立企业档案并创建企业管理员。企业管理员可查询本企业合同账单、提交资料变更和报修、创建受限成员。普通成员默认基本查询和报修，完整合同、资金和成员管理单独授权。

第一版不做短信注册与自助注册审核；执照上传不自动赋予历史合同权限。系统管理员管理账号和配置，园区经营数据仍须相应授权。一个账号归属一家企业、一家企业多个账号的边界沿用 Q7。

## Q14 意向与暂占

一张意向对应一个单元。报价不低于指导价时完成业务校验即可通过；低于指导价但不低于底价由招商经理审批；低于底价由招商经理、园区负责人依次审批并说明。免租等其他经济条件由合同审批一并复核。

审批通过时起暂占7天，记录拟租日期。暂占阻止冲突租期；第一版同单元最多一张有效意向暂占。合同审批原子接管占用，过期任务不得释放已转合同的占用。意向过期后需重新校验审批，不自动续锁。驳回、撤回与过期仅释放本单自己的占用。

实际占用、未来合同预订与意向暂占分别记录。当前承租人到6月30日结束，后续企业7月1日起租可以提前办理，但不得修改当前实际占用事实。

## Q15 合同、签署、交接与结算

审批、签署、约定租期、实际交接与财务结算分别记录。日期包含首尾，原合同6月30日结束，则相邻新合同7月1日起；占用区间包含免租期。

审批通过且已签署后可生成首期预收账单，不等待实际入驻。到约定起日且IN确认后登记实际占用；计费依据合同约定，交接录入滞后不自动改价。第一版不支持签署后直接修改租期或约定占用起日前提前交付。

到期但未交还保持实际占用，不能交给后续企业。OUT确认腾空后解除实际占用；提前退租还须完成合同终止及占用区间处理。未完成退款不阻塞已腾空房源后续出租。提前终止、押金和欠费按已确认的 Q22 处理。

## Q16 计费

租金、物业费采用元/平方米/月，合同逐单元确认计费面积、单价与含税口径并固化快照，调房源价格不改变历史合同。

支持1/3/6/12个月付款周期。合同开始月月初为账期锚点，首尾裁剪到合同真实区间，按自然月实际日历天数折算。只支持期初连续免租，物业费不随租金自动免除。可约定从计租日周年开始复利递增，未约定则不递增。

金额使用BigDecimal/DECIMAL。分段明细保存单元、日期、面积、单价、天数、递增次数与结果，逐明细四舍五入至分后汇总。出单时间与付款到期日分别约定。

示例仅为规则说明：1月15日至4月14日季付，账期为1月15日至3月31日、4月1日至4月14日。租金免至2月9日时从2月10日计租，物业费按约定从合同开始日计算。该示例未执行程序验证。

## Q17 账单、收款与更正

租金、物业费、押金分类型出账，同合同多单元保留明细。定时和人工补跑共用规则，重复执行不重复出账，停机能够补齐漏期。

一张账单可多次线下收款，每笔金额大于零、不超过剩余应收。一笔收款对应一张账单，跨账单到账由财务拆分登记。保存实际到账日期、方式、凭证、经办人、独立业务号及系统录入时间，到账日期与录入时间不混用。逾期后部分付款仍展示逾期与剩余金额。

错误收款仅全额红冲，由另一位有权限人员复核，保留原记录与更正流水。红冲用于记账更正，不代表实际退款；实际退款另记录资金事实。未收账单经审批可作废重开并保留关联；已收款账单不直接改金额，通过调整流程处理。

第一版不自动计提违约金，有合同依据的赔偿或费用调整人工说明、审批登记。

## Q18 合同审批与续租

新签与续租固定流程：合同专员提交→财务复核费用条款→园区负责人终审→签署归档。财务核对面积、单价、免租、递增、周期与押金。提交人不能审核本人提交合同；兼岗不得让同一单据经办与审核由一人完成。驳回返回草稿，修改后重新提交并保留历轮记录。

未签合同可取消释放预订，已有收款仍保留待退款事项。相同企业、相同单元、次日衔接的续租也须审批签署，衔接时原子承接实际占用，不伪造搬出搬入。押金转结与提前终止资金处理见 Q22。

## Q19 留资、预约与公海

匿名留资和看房申请由招商回访，访客不能直接查询内部处理进度。预约未来14天、09:00—12:00及14:00—18:00、每次30分钟、一预约一单元；时段作为配置。后台确认安排带看人员，同一单元、同一人员同一时段不得重复。

预约不产生租赁占用权；意向暂占期间可由运营安排带看，但不得承诺冲突租期。阶段可跳过，不补造带看等历史事件。公海首版手动退回、经理分配、授权人员原子领取、转交留痕，不自动按未跟进天数回收。

## Q20 工单与通知

企业仅对有权使用的单元报修，续租连续使用不影响报修。提交→受理/派单→处理→完工待确认→关闭；可返工回处理。完工保存结果、照片、处理人并生成站内待办。

企业确认后关闭；完工并生成通知起48小时无反馈可超时关闭，明确关闭原因，不视为企业验收、不自动评分。超时关闭后可申请返工，由运营受理并保留历史。

公告、审批、到期、工单通知采用站内待办、未读提示与定时刷新。无短信、邮件或WebSocket；紧急问题展示线下电话。

## Q21 统计口径

- 当前占用率：实际占用计租面积/纳入出租范围面积；维修单元保留分母，正式停用单元移出。未来预订不算实际占用。
- 可交付房源同时检查实际占用、合同区间、意向暂占及维修状态。
- 招商统计以同批线索截至指定日的真实带看、意向、签署事件为依据；可跳阶段时不伪造逐级漏斗，到期不抹掉历史签约。
- 账期回款展示指定账期账单应收、已核销收款和剩余；期间到账按实际到账日而非系统录入日。
- 押金单列收取、抵扣、退款与余额，不计租金收入。明细与汇总可复核。

## Q22 押金、退款与整合同终止结算

合同按类型登记约定押金金额，不强制多种保证金。押金账单实收后同事务更新台账和流水。抵扣经批准并关联具体应收，同时扣押金、核销欠费，重复请求不得二次处理。

退款申请、异人复核、实际执行分别记录；实际退款才减少余额，待执行金额保留额度，不得重复抵扣。续租可批准内部转结，旧合同转出、新合同转入成对留痕，不计新现金或租金。

提前退租整合同申请终止日、园区负责人批准，保留原条款与依据；OUT、终止及合同占用区间分别处理。财务按批准费用截止日结算，已发布账单不原地改历史，差额形成关联调整。多收预付租金列独立应退款，不混入押金。损坏赔偿及逾期占用费人工依据合同确认审批，欠费与应退抵销须留关联依据。

企业腾空且合同占用解除后不因欠费或退款未结继续锁房。退款仍不等于红冲。

## Q23 数据、API与资料边界

以当前规则核对正式数据模型，不照原38张备选表全部建库，保留旧设计对应关系。API统一 `/api`、分页/错误与状态冲突，资金和状态变化用业务命令。API金额使用十进制字符串，业务日期按 `Asia/Shanghai` 解释，日期时间格式与时区明确。

合同、账单、收款、结算不通过普通删除抹除，更正留依据；统一资源锁顺序、资金及资源幂等与过期编辑校验。私有附件支持图片/PDF，默认单文件20MB；同步Excel默认最多10000行，超限提示缩小范围。数据库与附件分别备份，须执行恢复验证。

数据关系与具体接口草案见 [数据与接口设计](data-api-design.md)。其中拟新增表名、字段名及命令属于实现设计，尚非数据库实际schema或已运行API。

## Q24 界面方向

浅色中性背景、深蓝重点。运营端工作台、租控、表格、详情与审批记录；门户园区与房源展示、咨询预约；企业端突出待办、合同账单及工单。门户企业端适配手机，运营端优先PC。采用必要趋势/构成/对比图表，不做3D园区或数字孪生；代表页面在实现前确认。

## Q25 实施与验收

1. 最小依赖验证并锁版本；第一阶段贯通登录园区授权、房源企业、意向、合同审批签署、IN、首期分段账单、部分收款、企业查询。
2. 补全账单调整、红冲、押金、续租、提前终止、抵扣与退款。
3. 门户预约、公海、企业成员、工单通知、统计导出。
4. 异常与并发、部署、备份恢复、虚构演示数据、截图和论文证据。

开发本地Maven/Node/MySQL，部署Nginx/jar/MySQL单实例，Compose可选。在线支付、能耗分摊、投资协议、政策申报本轮不实现，列后续扩展。不得预填测试与性能结果。

## Q26 关联资金的红冲约束

原收款已用于押金抵扣、转结或退款时，拒绝孤立红冲并显示关联记录。先按原业务完成有批准依据的关联更正，再申请原收款全额红冲并由另一人复核。已经真实退付的资金不得仅用反向记账视作收回；更正后账单、押金与现金事实必须可核对。

## Q27 提前终止的费用截止日

费用截止日默认与批准终止日一致；协议另有安排时，由园区负责人在终止审批中分别确认费用截止日与占用截止依据，财务不得直接改原合同日期。原始起止、批准终止、费用截止与实际OUT分别保留。

财务按批准费用截止日调整，实际交付必须同时检查合同占用与OUT。逾期未交还的额外费用人工按合同审批，不自动延长正常租金。

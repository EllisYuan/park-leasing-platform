## 目标与边界

面向一个园区运营商管理多个园区、服务多家承租企业。交付可运行演示的工程型毕业设计：前后端、版本化migration、虚构演示数据、关键验证和论文所需实际证据。工期与参与人数尚未提供，不据此前期12—16周假设承诺日程。

业务链：房源建档→招商线索与跟进→带看→报价意向审批与暂占→合同审批签署→交接起租→账单收款→续租或退租→押金结算。允许跳过实际未发生的招商阶段，不能伪造历史。

## 最终功能

| 功能组 | 交付内容 |
| --- | --- |
| 园区厂房 | 多园区、楼栋、完整出租单元、厂房条件、指导价底价、租控可用性 |
| 招商 | 线索需求、负责人、跟进带看、手动公海、意向报价及审批暂占 |
| 租赁 | 多单元合同、固定审批、签署扫描件、IN/OUT、到期、续租与整合同提前退租 |
| 账单资金 | 自然月分段租金物业费、分类账单、部分线下收款、调整红冲、押金抵扣转结与退款 |
| 招商门户 | 园区房源展示、筛选、详情、匿名留资和预约回访 |
| 企业中心 | 资料、管理员与受限成员、合同账单、收款记录、通知报修 |
| 物业工单 | 受理派单处理、完工确认、超时关闭与返工 |
| 统计导出 | 实际占用、招商事件、账期与现金、押金分类、基础Excel |
| 系统管理 | 员工角色、园区授权、企业核验绑定、字典公告待办与日志 |

## 人员与资源边界

员工角色按园区授予，可兼岗；操作权限与本人/部门/园区范围并行。管理员、负责人、招商经理/专员、合同、财务、物业分职责。系统管理员权限不自动扩为园区经营权限。经办不得自审，退款/红冲异人复核。企业账号一账号一家企业、一企业多账号；运营核验开户，管理员创建受限成员。所有列表、详情、导出、统计、附件与状态命令都检查后台数据归属。

资产为园区→楼栋→单元，楼层为属性，空间不重叠。合同一企业一园区、可多完整单元且共同租期，各自保留面积价格快照。跨园区或中途增租另签，不做部分退租；续租新合同关联原合同。

## 核心规则摘要

- 意向一单一单元，按指导价/底价审批，通过起暂占7天，过期重新校验；合同原子接管，旧意向不能误释放。单元首版最多一有效意向暂占，未来预订与当前实际占用分开。
- 合同提交→财务复核→负责人终审→签署。租期含首尾，免租仍占房，签署后不直接改租期或提前交付。审批签署后可出首期账单；到约定起日且IN后记实际占用。
- 租金物业元/平方米/月，1/3/6/12月周期，合同开始月月初锚点、首尾按当月天数折算；期初连续免租不自动免物业，可选计租周年复利递增；明细舍入汇总并保留算式。
- 分类出账、可部分收款，一款一单，金额不超余额；红冲是错误记账更正，不是实际退款。已发布账单通过调整处理，不覆盖历史。
- 押金分类与流水、抵欠核销同事务；待退款保留额度，异人复核后执行留凭证；续租转结成对记录不算新现金。预收租金应退与押金分列。
- 整合同提前终止保留原条款和批准截止日，调整费用、处理OUT与占用区间；财务未结不阻塞已腾空且合同占用解除的房源。到期未还仍不可交付。
- 预约未来14天、工作时段30分钟、房源及带看人员不冲突；手动公海，无自动回收。
- 工单完工通知起48小时可超时关闭，不视为验收、不评分、可申请返工；站内待办定时刷新，无短信邮件WebSocket。
- 实际占用率、未来预订、同批招商事件、账期核销、现金到账与押金分别统计。

## 界面与交付

一个Vue SPA三套布局：门户手机适配、企业端手机适配、运营PC优先。浅色中性背景加深蓝重点，后台台账与审批、门户园区房源展示、企业待办合同账单，基础图表；代表页面实现前确认。

四阶段：贯通招商到部分收款→完整财务续退租→门户企业工单统计→验证部署证据。阶段0先验证依赖。验收覆盖日期金额、并发与幂等、跨企业跨园区权限、附件导出、资金余额与恢复，不预填性能数字。
